# 🚗 CarModelDBApp

A console-based Java application that connects to a database of car records using JDBC and provides various useful queries and statistics on the cars in the system.

### 🔍 Features

- View **all car makes** stored in the database
- Identify the **oldest car model** based on manufacturing year
- Calculate the **total value** of all cars
- Determine the **most expensive** and **least expensive** car models
- Simple **menu-driven interface** using Java's `Scanner`

### 📦 Technologies Used

- Java (JDBC, SQL, OOP)
- Apache Derby or any JDBC-compatible database
- SQL Queries
- Command-line interface

### 📌 What I Learned

- Establishing database connections using JDBC  
- Executing SQL queries and handling `ResultSet` data  
- Writing clean, modular code with methods handling specific operations  
- Creating user-friendly console menus
